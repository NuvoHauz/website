# 08 RAW FOOTAGE — upload your clips here

Drop video files in this folder so the agent can review them and build Reels matched to **your** footage.

## How to upload

### Option A — Cursor desktop
1. Drag `.mp4` or `.mov` files into this folder in the file explorer.
2. Fill in one line per clip in [`CLIP-INVENTORY.md`](CLIP-INVENTORY.md).
3. Message the agent: **"Videos are in 08 RAW FOOTAGE — build Reels."**

### Option B — Chat attach (1–3 clips)
1. Click the paperclip in chat and attach the video.
2. Include filename + one-line description in your message.

### Option C — Phone → computer → here
AirDrop, iCloud, Google Drive, or Dropbox to your computer, then drag into this folder.

### Instagram Reels you already posted
IG → your Reel → menu → **Save video** → upload here for a new hook/caption/remake.

---

## File naming (recommended)

```
YYYY-MM-topic-location.mp4
```

Examples:
- `2026-08-fountain-square-walk-day.mp4`
- `2026-08-fountain-square-walk-night.mp4`
- `2026-08-indy-showing-kitchen.mp4`
- `2026-08-airbnb-turnover-towels.mp4`
- `2026-08-talking-head-investor-take1.mp4`

---

## File tips

| | |
|---|---|
| **Format** | `.mp4` or `.mov` (best) |
| **Length** | Any — even 3–8 sec B-roll is useful |
| **Size** | If 500MB+, compress before upload (phone Export Medium or HandBrake) |
| **Privacy** | No lock codes, contracts with client names, or guest faces without permission |
